- Complexity describes how the time or space of an algorithm scales as the input size grows.
- Steps of O(1) are considered atomic for relativeness. 
- Complexity analysis is independent of hardware like CPU speed and prog language advantages.

- Big-O , No matter what happens, it will never grow faster than this. ( ceiling ).
- Big-Ω , The algorithm will take atleast this much work. ( floor )
- Big-Θ , The growth is exactly like this no faster no slower

- Single loop - O(n)
- Sequential loop - O(n)
- Nested loop - O(n ^ 2)

- Input size - size occupied by input space , Auxilary space - additional memory used by algorithm.
