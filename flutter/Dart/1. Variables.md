- `var` is used as a type identifier for local variables. type is inferred at runtime.
- `Object` and `dynamic` can be used to store variety of values in a variable.
- type of variable can also be used as type identifier.

##### Null Safety

- Null safety prevents null dereferencing error which happens when a propery or method is accesed on a null value.
- variables are declared as nullable ( ends with `?` ) or non-nullable.
- non-nullable variables are expected to be intialized before using them , whereas nullable variables are given a default value of null.
- This converts runtime errors to edit time analysis errors.
``` dart
String name;
String? name = 'Jon';
```

##### Late type modifier

- `late` can be used to enable initializing top level variables that are just declared. Dart might not check before using them if they are initialized so it forces us to initialize them.
- this makes edit time errors back to run time errors.
- `late` also lazily runs the initialization code if used at declaration. In case of big initilizer funs, time can be saved if they arent used.
``` dart
late String name;
...
print(name) // might cause runtime error
...

late String temp = heavyTempFun(); // only runs if temp is used
```

##### Final and Const

- `final` variables are assigned once at runtime can cannot be modified later.
- contents of `final` variables are mutable.

- `const` variables are assigned at compile time and they are completely immutable.
- const objects are canonicalized , i.e same refernce are used for identical objects.
``` dart
var foo = const [];
final bar = const [];
const baz = []; // Equivalent to `const []`
```

- foo can be assigned a new value but does not allow mutation . bar becomes immutable.

``` dart
class Point {
  final int x;
  final int y;
  const Point(this.x, this.y);
}

const p1 = Point(1, 2);
const p2 = Point(1, 2);

print(identical(p1, p2)); // true (canonicalized)
```

- `const` constructor enables to generate instances at compile time . whereas `const` at call site asks to create an instance at compile time.
- `const` constructor can be ommited to recieve run time parameters.

|Constructor|Call Site|Result|
|---|---|---|
|`const`|`const`|Compile-time object, canonicalized ✅|
|`const`|no `const`|Runtime object, fresh instance 🆕|
|non-`const`|`const`|❌ Error|
|non-`const`|no `const`|Runtime object, fresh instance 🆕|
``` dart
const Object i = 3; // Where i is a const Object with an int value...
const list = [i as int]; // Use a typecast.
const map = {if (i is int) i: 'int'}; // Use is and collection if.
const set = {if (list is List<int>) ...list}; // ...and a spread.
```
