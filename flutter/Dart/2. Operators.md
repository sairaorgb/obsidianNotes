##### Arthimetic operators
- `+`,`-`,`*`,`/` are usual arthimetic operators.
- `/` give result as double. `~/` give integer part of divison . `%` give modulus of divison.
- prefix and postfix increment and decrement are also available.

##### Equality and relational operators
- `==`,`!=`,`<`,`>`,`<=`,`>=` are included in this set.
- These operators act as methods on first operand with second operand as argument.
- To check if two objects are exactly same , identical() function can be used.

##### Type test operators
- `as` - Typecast ( bypasses compile time checks )
- `is` - True if object has specified type
- `is!` - True if object does not have specified type
- The result of `obj is T` is true if `obj` implements the interface specified by `T`.
``` dart
(employee as Person).firstName = 'Bob';

if (employee is Person) {
  // Type check
  employee.firstName = 'Bob';
}
```

**Cascading operator**

- Cascades `...`,`?..` allow you to make sequence of operations on same object.
- cascade should be constructed on a function that returns an actual object.
``` dart
var paint = Paint()
  ..color = Colors.black
  ..strokeCap = StrokeCap.round
  ..strokeWidth = 5.0;
  
paint.color = Colors.black,
paint.strokeCap = StrokeCap.round,
```

``` dart
document.querySelector('#confirm') // Get an object.
  ?..textContent =
      'Confirm' // Use its members.
  ..classList.add('important')
  ..onClick.listen((e) => window.alert('Confirmed!'))
  ..scrollIntoView();
```

- cascades can be nested.
``` dart
final addressBook =
    (AddressBookBuilder()
          ..name = 'jenny'
          ..email = 'jenny@example.com'
          ..phone =
              (PhoneNumberBuilder()
                    ..number = '415-555-0100'
                    ..label = 'home')
                  .build())
        .build();
```

**Other operators**

- `()` - Function application 
- `[]` - Subscript access 
- `?[]` - conditional subscript access ( retuns null if left op is null )

- `.`- Member access
- `?.`- Conditional Member access - null aware access , if left op is null returns null
- ?? - if null operator - if left op is null returns fallback i.e right one 
- `??==` - null aware assignment operator - assigns value only if left variable is null


- `!`- Not null assertion operator - asserts left operand as a non-nullable so if it's not it causes runtime error
