
#### Classes

- `objects` have members consisting of functions and data ( methods and instance variables ) , can be used with `.` operator.

- `new` keyword is optional when generating objects from a constructor.
- some classes provide `const` constructors , which take compile time constants and give a const object if const is added before constructor.
``` dart
var p = const ImmutablePoint(2, 2); // const object
var p = ImmutablePoint(2, 2); // not a const object
```
- objects from same const constructor are idential due to canonicalisation of consts by dart

**Instance Variables**

- Instance varibles , are null if they are declared nullable and uninitialized or they must be initialized before constructor ends.
- In a class , space for class if first allocated -> Field initializers run ( plain = ) -> initializer list ( : name = something ) runs -> constructor body runs. 
- so `this` cannot be used in field initializers where it might not yet be completely built , whereas it can be used inside later steps.

- `late` modifier makes compile time check to initialize instance variable before constructor into runtime .
- `final` allows to only initialize once that too before constructor body ( constructor parameter or initializer list ) . whereas variables with no type modifiers can be initialized inside constructor body.

- for a constructor to `const` , all instance variables must be const or final which makes them immutable at compile time . `late` gets disqualifed because they can go uninitialized till they are used. general variables are disqualifed as they are mutable.
- `final` list as instance variable must be assigned a const list.

**Interface** 

- Every class implicitly defines an interface containing all the instance members of the class and of any interfaces it implements. 
``` dart
class Person {
  // In the interface, but visible only in this library.
  final String _name;
  // Not in the interface, since this is a constructor.
  Person(this._name);
  // In the interface.
  String greet(String who) => 'Hello, $who. I am $_name.';
}
```

- static variables and methods are available without creating an object of class.
