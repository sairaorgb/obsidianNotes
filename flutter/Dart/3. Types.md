#### Numbers

- `num` is a superclass of `int` and `double` in which numbers can be represented.
``` dart
// integer literals
var x = 1;
var hex = 0xDEADBEEF;
// double literals
var y = 1.1;
var exponents = 1.42e5;
```
- `num` can store both int and double literals.
- type coercison happens between `int` and `double` types with other literals.
- `int.parse()` and `double.parse()` are used to convert strings to nums.
- var. `toString()` and `toStringAsFixed()` are used to convert nums to strings.
- underscores can be used as digit seperators.

#### Strings

- `''` or `""` can be used for a string literal.
``` dart
String s = 'This''is a'"string too";
// raw strings where delimiters wont work
String rawString = "this is \n raw string where \n not works";
// string interpolation
String instring = '$s' + "salar";
```

- `{}` can be skipped if underlying var is literal. const strings must have const values inside them interpolated

#### Records

- Records are a bundle of positional and named field which are immutable and hetro typed.
- comma-delimited . Record type annotations are comma-delimited lists of types enclosed in parentheses.
- record fields are immutable so they only have getters and dont have setters.
- A record's shape (the set of its fields, the fields' types, and their names, if any) uniquely determines the type of a record.
``` dart
(String, String, {int a , int b} ) record;
record = ('first', a: 2, b: true, 'last');

print(record.$1); // first
print(record.$2); // last
print(record.a); // 2 
print(record.b); // true
```

- Two records are equal if they have the same shape (set of fields), and their corresponding fields have the same values.
``` dart
(int x, int y, int z) point = (1, 2, 3);
(int r, int g, int b) color = (1, 2, 3);

print(point == color); // Prints 'true'.

({int x, int y, int z}) point = (x: 1, y: 2, z: 3);
({int r, int g, int b}) color = (r: 1, g: 2, b: 3);

print(point == color); // Prints 'false'. Lint: Equals on unrelated types.
```

- multiple values can be bundled together and returned as a record
``` dart
// Returns multiple values in a record:
(String name, int age) userInfo(Map<String, dynamic> json) {
  return (json['name'] as String, json['age'] as int);
}

final json = <String, dynamic>{'name': 'Dash', 'age': 10, 'color': 'blue'};

// Destructures using a record pattern with positional fields:
var (name, age) = userInfo(json);
```

- records can be used as simple data structures and an alias can be created out of type definition of a record and can be used multiple times. for further info check out [addon](https://dart.dev/language/records#records-as-simple-data-structures)
