#### Numbers

- `num` is a superclass of `int` and `double` in which numbers can be represented.
``` dart
// integer literals
var x = 1;
var hex = 0xDEADBEEF;
// double literals
var y = 1.1;
var exponents = 1.42e5;
```
- `num` can store both int and double literals.
- type coercison happens between `int` and `double` types with other literals.
- `int.parse()` and `double.parse()` are used to convert strings to nums.
- var. `toString()` and `toStringAsFixed()` are used to convert nums to strings.
- underscores can be used as digit seperators.

#### Records

- Records are a bundle of positional and named field which are immutable and hetro typed.
- comma-delimited . Record type annotations are comma-delimited lists of types enclosed in parentheses.
- record fields are immutable so they only have getters and dont have setters.
- A record's shape (the set of its fields, the fields' types, and their names, if any) uniquely determines the type of a record.
``` dart
(String, String, {int a , int b} ) record;
record = ('first', a: 2, b: true, 'last');

print(record.$1); // first
print(record.$2); // last
print(record.a); // 2 
print(record.b); // true
```

- Two records are equal if they have the same shape (set of fields), and their corresponding fields have the same values. hashcodes and == are available.
``` dart
(int x, int y, int z) point = (1, 2, 3);
(int r, int g, int b) color = (1, 2, 3);

print(point == color); // Prints 'true'.

({int x, int y, int z}) point = (x: 1, y: 2, z: 3);
({int r, int g, int b}) color = (r: 1, g: 2, b: 3);

print(point == color); // Prints 'false'. Lint: Equals on unrelated types.
```

- multiple values can be bundled together and returned as a record
``` dart
// Returns multiple values in a record:
(String name, int age) userInfo(Map<String, dynamic> json) {
  return (json['name'] as String, json['age'] as int);
}

final json = <String, dynamic>{'name': 'Dash', 'age': 10, 'color': 'blue'};

// Destructures using a record pattern with positional fields:
var (name, age) = userInfo(json);
```

- records can be used as simple data structures and an alias can be created out of type definition of a record and can be used multiple times. for further info check out [addon](https://dart.dev/language/records#records-as-simple-data-structures)

#### Collections

**Lists**
- An ordered group of same typed objects. `List<type>`.
- indexing , methods all work . type is inferred if var is used.
``` dart
var ids = [1,2,3];
ids[ids.length-1] = 2;
var constantList = const [1, 2, 3];
```

**Sets**
- unordered collection of unique elements with same type.
- empty set is created using `<type>{}` , empty map is `{}`.
- `add()` and `addAll()` can be used to add elements.

``` dart
var names = <String>{};
// Set<String> names = {}; // This works, too.
// var names = {}; // Creates a map, not a set.
final constSet = const {'a','b','c'};
```

**Maps**
- In a Map, each element is a key-value pair. Dart infers type to be Map<fs type,snd type>.
- `new` keyword isnt necessary while using map or any constructor.
- subscript , length and declaring const before map literal to make it const.
``` dart
// using map constructor to declare a map
var gifts = Map<String, String>(); 
gifts['first'] = 'partridge'; 
gifts['second'] = 'turtledoves'; 

```

#### Collection Elements

A collection literal contains a series of elements. During runtime, each element is evaluated, producing zero or more values that are then inserted into the resulting collection. These elements fall into two main categories: leaf elements and control flow elements.
- `Leaf element`: Inserts an individual item into a collection literal. It includes `Expression element` and `Map entry element`.
- `Control flow element`: Conditionally or iteratively adds zero or more values to the surrounding collection. includes Null-aware element , spread element , Null aware spread element , if and for element


An expression element that encompass various constructs like literals,variables,operators,function calls and constructor calls. collection literals can contan these as :
``` dart
var ids = [1,<expr>,4];
var matches = [1:"sair",<key_expr>:<val_expr>];
```


- **Null-aware operator** before expr inserts the values only if the expr evaluates to non-null value or gets ignored.
- In case of map expr's , null-aware on either key or value means that both key and value must be non-null;
``` dart
?<expr>
?<key_expr> : <val_expr>

int? absentValue = null;
int? presentValue = 3;
var items = [ 1, ?absentValue, ?presentValue, absentValue, 5,]; // [1, 3, null, 5]

```

- **Spread elements** iterates over a given sequence and inserts all of the resulting values into the surrounding collection.
- sequence expression that comes after spread operator must implement Iterable 
- Null - aware spread elements have ? operator before ... to create an effect only if the expr is not null.
``` dart
var a = [1, 2, null, 4];
var items = [0, ...a, 5]; // [0, 1, 2, null, 4, 5]
var itemd = [9,?...a];
```

- An `if` element conditionally evaluates an inner element based on given a condition expression, and optionally evaluates another else element if the condition is false.
``` dart
if (<bool_expression>) <result>
if (<expression> case <pattern>) <result>
if (<bool_expression>) <result> else <result>
if (<expression> case <pattern>) <result> else <result>
```
``` dart
var name = 'apple';
var items = [
  0,
  if (name == 'kiwi') 1 else if (name == 'pear') 10,
]; // [0]
```

- A for element iterates and repeatedly evaluates a given inner element, inserting zero or more resulting values.
``` dart
for (<expression> in <collection>) <result>
for (<initialization_clause>; <condition_clause>; <increment_clause>) <result>
```
``` dart
var numbers = [1, 2, 3, 4, 5, 6, 7];
var items = [
  0,
  for (var n in numbers)
    if (n.isEven) n,
  8,
]; // [0, 2, 4, 6, 8]
```
- nested if and for loops can be used as well in collection literals
