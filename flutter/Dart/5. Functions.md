- Functions are objects and have a type `Function`. They can be passed as arguments or can be assigned to variables.
- parameters can be positional or named. They can be mandated or defaulted too.

``` dart
// named parameters 
void enableFlags({bool? bold,bool? hidden}) {}
void enableFlags({required bool bold,bool hidden = true}) {}

// positional parameters
void enableFlags(bool bold,bool hidden) {}
void enableFlags(bool bold, [bool hidden]) {}
```


### Callbacks

- Functions have type signatures that constitues types of arguments and return values.
- `typedef` is  a keyword used to reperesent an alias for a functions type sign. 
``` dart
int add(int a, int b) => a + b; // type sign : int Function(int,int)

typedef voidCallback = void Function();

typedef IntCombiner = int Function(int a, int b);
int operate(IntCombiner op) => op(2, 3);
```

- Callbacks for positional and named parameters differ slightly. type compatibility the shape (names + required flags + types) must align. `required` is part of the type.
``` dart
// positional arguments
int Function(int, int) addType;
int Function(int, [int?]) maybeAddType;

typedef Adder = int Function(int a, int b);
typedef MaybeAdder = int Function(int a, [int? b]);

int combine(int a, [int? b]) => a + (b ?? 0);

// named arguments
void Function({required String name, int? age}) fnType;
typedef PersonHandler = void Function({required String name, int? age});

void greet({required String name, int? age}) {
  print('Hi $name, age ${age ?? "unknown"}');
}
```

- Nullable function types - `?` sign  at the end makes the entire type sign nullable , which makes it to either hold a functional type sign or null. similarly `?` can be used on args and return values.
``` dart
VoidCallback? onPressed;          
void Function()? maybeCallback;   

onPressed?.call(); // invoke call() method if left operand is not null 

// function takes nullable String, returns nullable int
int? Function(String?) parseMaybe;
```

- Higher order callbacks - callbacks that return functions.
``` dart
typedef IntToString = String Function(int);
typedef Factory = IntToString Function(String prefix);

String Function(int) maker(String prefix) => (int n) => '$prefix$n';
Factory f = maker;
var fn = f('id: ');
print(fn(7));  // prints 'id: 7'
```
