**Quirk with onChanged:**

- when an `onChanged` argument expects `void callback()` , even if int Function() is passed down as a parameter it still accepts it and discards returned int. 
``` dart 
// saveTask has type sign of void Function()
void saveTask(){
   print("sabar");
}
// if onPressed expects void callback()
onPressed : () => saveTask(); // void Function()
onPressed : () => saveTask;   // void Function() Function() - ret fn is discared 
onPressed : saveTask;         // void Function()
```
