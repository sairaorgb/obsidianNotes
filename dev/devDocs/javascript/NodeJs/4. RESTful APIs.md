- An API ( application programming interface ) acts a medium for data transfer between server and client.
- Along with REST ( representational state transfer ) , there are other API styles that include `GraphQL` : related data can be nested within which will reduce queries but may increase cost of queries , `gRPC` :  uses protobuff , backend to backend and streaming support 

**Features of REST apis**
- Client server model 
- Resources identified by URLs
- Use of HTTP methods
- Statelessness
- JSON ( js object notation ) resources 
- Uniform interface ( independent of client )

**Extras of REST Apis**
- Take care of HTTP codes in response. (200, 201, 400, 401, 403, 404, 500)
- Each request might carry API keys or JWT tokens for authentication
- Versioning - Evolved apis should be given diff path to still maintain older ones.
- Idempotency - GET,PUT are safe to call twice, but POST PATCH have different effect on identical calls. 
- Caching and performance 
- Pagination and filtering 
- HATEOAS - Hypermedia as the Engine of Application state - raw urls can be put inside responses to facilitate further api calls from client based on requirement.

#### Coding stuff 

**consuming REST API ( client side )**

- In javascript ( Node or browser)
``` js
// GET request
fetch('https://jsonplaceholder.typicode.com/users/1')
  .then(res => res.json())
  .then(data => {
    console.log(data); // prints user info
  })
  .catch(err => console.error(err));
  ```
  - POST request ( create resource )
``` js
fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    title: 'REST APIs rock',
    body: 'This is my first API POST',
    userId: 1
  })
})
.then(res => res.json())
.then(data => console.log(data));
```

**Building REST API ( server side with Express )**

``` js
const express = require('express');
const app = express();

app.use(express.json()); // middleware to parse JSON

// In-memory "database"
let users = [{ id: 1, name: "Sairaorg" }];

// GET all users
app.get('/users', (req, res) => {
  res.json(users);
});

// GET one user
app.get('/users/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  user ? res.json(user) : res.status(404).send("User not found");
});

// POST (create user)
app.post('/users', (req, res) => {
  const newUser = { id: users.length + 1, ...req.body };
  users.push(newUser);
  res.status(201).json(newUser);
});

// PUT (update user)
app.put('/users/:id', (req, res) => {
  const index = users.findIndex(u => u.id === parseInt(req.params.id));
  if (index === -1) return res.status(404).send("User not found");
  users[index] = { id: parseInt(req.params.id), ...req.body };
  res.json(users[index]);
});

// DELETE
app.delete('/users/:id', (req, res) => {
  users = users.filter(u => u.id !== parseInt(req.params.id));
  res.status(204).send();
});

app.listen(3000, () => console.log("API running on http://localhost:3000"));

```
