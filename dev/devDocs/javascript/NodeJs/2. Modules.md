**Modules** enable us to organize code into reusable maintainable units. 
- CommonJS ( traditional ) and ES Modules ( ECMAscript )
- core modules include fs , http , path , os , events , util , stream , url and many more.

#### Common JS 

``` js
const http = require('http');    // using core built in modules (commonjs)
```

**Exporting functionality from a module**:

- Exporting multiple methods
``` js
// sampleFile.js
const method1 = ()=>{};
const method2 = ()=>{};

// Exporting multiple items
exports.method1 = method1;
exports.method2 = method2;

// Exporting an object with multiple properties
module.exports = { getCurrentDate, formatCurrency };
```
- Exporting single thing
``` js
// sampleFile2.js
class Logger {
  constructor(name) {
    this.name = name;
  }
  method1(){};
  method2(){};
}

// Exporting a single class
module.exports = Logger;
```

**Importing Modules**
- Apart from core built in modules , modules from other files can be imported into current file.
``` js
const http = require('http');
const path = require('fs');

const { method1, method2 } = require('./sampleFile.js');
const Logger = require('./sampleFile2.js');
```

- NodeJS catches modules after the first time they are loaded. 
- NodeJs looks for in this order : core modules , node modules in node_modules foldre and local files using ./ and ../ prefix .

#### ES Modules

- use .mjs file extension but works with js ( with proper config ) . supports static import , top level awaits and file URL in imports
- setting "type":"module" in package.json , makes all js files as es modules .
- node --input-type=module script.js

**Export syntax**

- Multiple Named Imports
``` js
export function sayHello() {
  console.log('Hello');
}

export function sayGoodbye() {
  console.log('Goodbye');
}
```

- Export List at the End
``` js
function add(a, b) {
  return a + b;
}

function subtract(a, b) {
  return a - b;
}

export { add , subtract }
```

- Default Export
``` js
// Only one default export per module  
export default function() {  
  console.log('I am the default export');  
}  
  
// Or with a named function/class/object  
function mainFunction() {  
  return 'Main functionality';  
}  
  
export default mainFunction;
```

- Mixed Exports
``` js
// Combining default and named exports  
export const VERSION = '1.0.0';  
  
function main() {  
  console.log('Main function');  
}  
  
export { main as default }; // Alternative way to set default
```

**Import Syntax**

- importing named exports
``` js
// Import specific named exports
import { sayHello, sayGoodbye } from './greetings.mjs';
sayHello(); // Hello

// Rename imports to avoid naming conflicts
import { add as sum, subtract as minus } from './math.mjs';
console.log(sum(5, 3)); // 8

// Import all named exports as an object
import * as math from './math.mjs';
console.log(math.add(7, 4)); // 11
```

- Importing Default Exports
``` js
// Import the default export  
import mainFunction from './main.mjs';  
mainFunction();  
  
// You can name the default import anything you want  
import anyNameYouWant from './main.mjs';  
anyNameYouWant();
```

- Importing Mixed Exports
``` js
// Import both default and named exports  
import main, { VERSION } from './main.mjs';  
console.log(VERSION); // 1.0.0  
main(); // Main function
```

- ES Modules support dynamic imports, allowing you to load modules conditionally or on-demand.
