Express.js is a Node.js web app framework designed for building web applications and API's.

###### Internals of Express

- Express is a foreign node module that gets imported into current codebase. 
- Express exports a Intialization function (`express` in ex ) which gets called and the return value is placed in app ( `const app = express()`)
- consider miniExpress.js , app ( fn in express source code ) is a callback function which gets passed down as callback of createServer method. so app function gets called everytime a request comes. 
- `app.listen` takes port and a cb which gets passed down as args for server.listen.
- Routes is an array that contains which function to invoke in different scenarios corresponding to method ( req.method ) and path ( req.url ) and the handler is that function.

``` js
// mini-express.js

const http = require("http");

function createApplication() {
  const routes = [];
  const app = function (req, res) {
  const route = routes.find(r => r.method === req.method && r.path ===req.url);
		if (route) {
		  return route.handler(req, res);
		}
		res.statusCode = 404;
		res.end("Not Found");
   };

  app.get = function (path, handler) {
	routes.push({ method: "GET", path, handler });
   };

  app.listen = function (port, cb) {
	const server = http.createServer(app);
	return server.listen(port, cb);
   };
   
  return app;
}

module.exports = createApplication;
```
``` js
// usage.js

const express = require("./mini-express");
const app = express();

app.get("/", (req, res) => {
  res.end("Home Page!");
});

app.get("/about", (req, res) => {
  res.end("About Page!");
});

app.listen(3000, () => console.log("Server running..."));

```
###### Basic Routing

- Routing refers to how an application responds to client requests to specific endpoints(URIs) using different HTTP methods.
``` js
// Respond to GET request on the root route
app.get('/', (req, res) => {
  res.send('GET request to the homepage');
});

// Respond to POST request on the root route
app.post('/', (req, res) => {
  res.send('POST request to the homepage');
});

// Respond to GET request on the /about route
app.get('/about', (req, res) => {
  res.send('About page');
});

// Catch all other routes
app.all('*', (req, res) => {
  res.status(404).send('404 - Page not found');
});
```


- Route parameters are named URL segments that capture values at specific positions in URL
``` js
// Route with parameters for /users/:userId/books/:bookId

app.get('/users/:userId/books/:bookId', (req, res) => {
  // Access parameters using req.params
  res.send(`User ID: ${req.params.userId}, Book ID: ${req.params.bookId}`);
});
```

- Query parameters are key value pairs after ? in URL and can be captured by req.query
``` js
// Route handling query parameters for URL
// http://localhost:8080/search?q=express&category=framework

app.get('/search', (req, res) => {  
  // Access query parameters using req.query  
  const { q, category } = req.query;  
  res.send(`Search query: ${q}, Category: ${category || 'none'}`);  
});
```

**Properties on req**

- `req.body` - comes from body parsing middleware 
- `req.query` - Parsed from query string in the URL
- `req.params` - Parsed from route placeholders 
- `req.headers`- All request headers as an object 
- `req.method` - HTTP method
- `req.url` - raw URL string 
- `req.path` - just the path of URL part
- `req.hostname` - Hostname of request
- `req.protocol` ,`req.ip` , `req.get(headerName)`, `req.is(type)`,`req.accepts(type)`

#### Middleware 

- Middeware - functions that sit between request and response. They can read/modify req and res, End the response or call next() to pass control down the chain .
``` js

// Middleware to parse JSON request bodies
app.use(express.json());

// Middleware to parse URL-encoded request bodies
app.use(express.urlencoded({ extended: true }));

// Middleware to serve static files from a directory
app.use(express.static('public'));

// Custom error handling middleware  
// Must have four parameters to be recognized as an error handler  
app.use((err, req, res, next) => {  
  console.error(err.stack);  
  res.status(500).send('Something broke!');  
});

// POST route that uses JSON middleware
app.post('/api/users', (req, res) => {
  // req.body contains the parsed JSON data
  console.log(req.body);
  res.status(201).json({ message: 'User created', user: req.body });
});

app.listen(port, () => {
  console.log(`Example app listening at http://localhost:${port}`);
});
```

`express.json()` - parses JSON request bodies.
- parses request with Content-type : application/json
- converts body of request ( ex : POST ) in raw json to js objects. 

`express.urlencoded()` - parse URL encoded request bodies
- parses request with content-type : application/x-www-form-urlencoded
- typical format from HTML forms for URLSearchParams.
- extended:true arg allow nested objects

`express.static()`- serve static files
- serves files directly from folders.
- Maps URL pathnames to filesystem paths

`express.router()` - create modular route handlers
- router can be used to contain relative path routes , which then be attached to main file along with a common path. 
- Groups related routes into modules. 
- can have route handlers , supports multiple middleware/handlers per route , can mount middleware scoped to that router , routers can be nested.

##### Serving static files

- `express.static()` can be used to serve static files. 
``` js
// looks up public dir for all requests
app.use(express.static('public')));  

// first arg virtual path in reqeust will be replace by public
app.use('/static', express.static('public'));
```
