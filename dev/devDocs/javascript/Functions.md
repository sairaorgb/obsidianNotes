#### Intro

- Functions can be used as declarations or as expressions,  declared ones are hoisted while the latter are not. 
- parameters are variables that store the arguments passed with functional call.
``` js
// Default params
function greet(name = 'stranger){}

// rest params
function sum(a,b,...nums){ // nums is taken as an array  }
sum(1,2,3,4,5,6);
```
- **Rest and Spread** includes a syntactical sugar to pass down multiple arguents once. 
	- Rest     =  gather ( many to one array )
	- Spread = scatter ( one to many array )
- No return , returns undefined.
