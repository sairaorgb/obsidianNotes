- variables store references. In general case , `var` is used which auto infers data type from assignment and stay that way.
- `object` or `dynamic` can be used for storing variables whose type can be changed midway.
``` dart
var name = 'Bob';
Object name = 'Bob';
String name = 'Bob';
```
**Null safety**
- variables can be nullable ( type ends with `?`) or non-nullable.
- Null safety prevents null dereferencing error that occurs when an expression that evaluates to null is used against a property.
- Nullable variables are intialized to null by default wherease non-nullable variables are to be intialized at any time before using them.
``` dart 
String name = 'Bob';
String? name;
```

**Late variables**
- late modifier has two use cases that are Declaring a non nullable variable that's initialized after its declaration and lazily initializing variable.
``` dart 
late String desc;
desc = "djadjka";

late String temp = getTemp();
```
