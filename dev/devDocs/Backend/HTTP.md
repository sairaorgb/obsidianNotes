#### HTTP messages

- HTTP is a protocol that governs the data flow through internet. Clients send requests to server for which server send responses back.
- HTTP requests include Request line ( HTTP method,path to resource and version ) , Headers ( Host (domain name) , user-agent and Accept (ty of content )) and optional Body.
- HTTP responses include status line, Headers and Body.

**HTTP status code**

- 1xx - Informational
- 2xx - Success
- 3xx - Redirection
- 4xx - Client Error
- 5xx - Server Error
